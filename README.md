# (TITULO DEL PROYECTO)

## Idea Inicial
Construir un editor de Markdown que:
- se puede acceder desde el navegador
- permite visualizar los Markdowns de forma linda, como lo hace obsidian
- permite la facil escritura de ecuaciones matematicas (Utilizando Latex)
- se puede utilizar para la documentacion de codigo
- utiliza google drive para almacenar las notas del usuario (Es una idea, depende de lo que opine el resto del equipo)
- procesa pdfs y los pasa a markdown (Es una idea, depende de lo que opine el resto del equipo)

## Porque es importante?
Genera las siguientes ventajas:
- las notas se pueden acceder desde cualquier lugar
- el usuario puede descargar sus notas para que sean procesadas por la IA, sin gastar demasiados tokens
- permite escribir ecuaciones matematicas permitiendo al usuario tener todas sus notas en un solo lugar, ya que muchas veces es dificil tomar notas de ese tipo de cosas
